# Harbour Inn demo — 给 SuiFei

这是一页给店老板看的门面站 demo，不是上线站，也不是报价单。文件在 `/workspace/demos/harbour-inn-padstow/index.html`。用手机打开即可。

没有联系店家。没有自称程序员。页脚只有店名和 Padstow。下面一小排「Also around」是别的店，不是作品集，也不含本店。

## 哪些是占位 / 故意没写

- **菜名和价格**：他们自己的菜单页没有一道菜名。第三方目录里有 mussels / fish and chips 等，这页没放。厨房只写钟点。
- **harbourinnpadstow.co.uk**：没有链成「我们的官网」。这页是替换草图。现站是 Wix，浏览器标题还写 **My Site**——只记在 `source.md`，不要当攻击念给老板听。
- **info@mysite.com**：模板残留，页面禁用。
- **卫生评分**：FSA 2026-05-12 查过（处理 Good，清洁 Good，管理 Very good），页上没放，避免在没有总分数字时猜 5 分。
- **Companies House**：HARBOUR INN (PADSTOW) LIMITED（05403572）已于 2024-11-05 解散。页上没写。
- **CAMRA** 里的 Peace Oss、台球桌、淹过水的石板地：不是他们自己的正文，没写。
- **2024 年博客义演**：过期了，没写。
- **Facebook / Instagram**：联系页有「Social Media」标题，公开文字里没有账号，没猜。

第三方钟点有打架（有的写周六收到 10:30、周日收到 22:30）。开口时认他们自己页脚那一张：十一点到十一点。

## 建议怎么开口

先把手机递过去，让他自己往下划。不要先讲技术，不要说「我是做网站的」，也不要贬他们现在那一页。

可以这样说：

> 按你们自己写的店名、南码头地址、钟点和那句不接受预订，做了一页给您看。菜单没编——你们网上菜单页本来就没有菜名，厨房只写了中午十二点到三点、晚上五点到八点。想坐下就直接来，这页不会假装能订位。电话和邮箱按下去就能打、能发。

等他看完，再问两件具体的：

1. 菜单要不要换成厨房那一版（现在这页故意空着，只留钟点）。
2. 周四开放麦、周五原声、周日钢琴，还是现在这三场吗——有改就换一句。

他如果觉得不像，就收起来。这页的用处是让他先看见自己的店，不是说服他买网站。
